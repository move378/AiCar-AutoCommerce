## AC-1: 마이페이지 메인 화면
```gherkin
Given 로그인 + 약관동의 완료 상태
When 차고 헤더 톱니바퀴 아이콘 탭
Then 마이페이지가 표시됨:
  - 배경 slate-100 (#F1F5F9)
  - AiCarHeader "마이페이지" + 뒤로가기
  - 프로필 섹션 (아바타 + 사용자명 + 로그인 provider)
  - 메뉴 리스트: 회원정보 수정, 이용약관, 개인정보 처리방침, 위치기반 서비스 이용약관, 로그아웃
  - 각 메뉴 아이템 탭 시 해당 페이지로 push
  - 공지사항, 1:1문의 메뉴 없음 (백엔드 미구현)
```

## AC-2: 회원정보 수정 (ProfileEditPage)
```gherkin
Given 마이페이지에서 "회원정보 수정" 탭
When 프로필 정보 페이지 진입
Then 표시됨:
  - 헤더: "프로필 정보" + X 닫기 버튼
  - 2탭: "차량 보유 계정" / "소셜 전용 계정"
  - [차량 보유 계정 탭]:
    - 차량정보: 소유자 입력 + 차량번호 입력 + 조회 버튼
    - 조회 결과 카드 (모델명, 연식, 최초등록)
    - 연결계정 (카카오/애플/구글 상태 표시)
  - [소셜 전용 계정 탭]:
    - "등록된 차량이 없습니다" + 차량등록 유도
    - 기본정보: 닉네임 입력
    - 연결계정 (동일)
  - 하단: 변경하기 버튼 (solid, full-width)
  - 하단: 회원탈퇴 텍스트 버튼 (Figma에 없지만 필수 요구사항)
```

Then 해당 페이지 표시:
  - AiCarHeader + 해당 제목 + 뒤로가기
  - 스크롤 가능한 텍스트 본문 (MVP placeholder)
  - 흰색 배경
