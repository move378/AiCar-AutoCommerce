<objective>
## Goal
Figma 차고 UI 디자인 기반으로 3탭 구조(가상차고/북마크/최근본)를 구현하고, 마이페이지에 프로필 + 설정 메뉴를 구현한다.

## Purpose
사용자가 챗봇→카드 추천→가상차고 저장 플로우를 완성하고, 저장된 차량을 다양한 뷰(캐러셀/그리드/리스트)로 탐색할 수 있어야 한다.

## Output
- `garage_page.dart` — 3탭 (가상차고 캐러셀 + 북마크 그리드 + 최근본 리스트)
- `garage_provider.dart` — 저장된 카드 상태 관리
- `garage_card.dart` — 가상차고 탭 전용 다크 카드 위젯
- `i_card_repository.dart` — getSavedCards, removeFromGarage 추가
- `my_page.dart` — 프로필 + 설정 메뉴 + 로그아웃
</objective>

## AC-1: 차고 3탭 구조
```gherkin
Given 차고 탭에 진입
When 페이지가 로드됨
Then 상단에 "가상 차고 | 북마크 | 최근 본" 3개 탭이 표시된다
And 탭 전환 시 해당 콘텐츠가 표시된다
```

## AC-2: 가상 차고 탭 — 다크 카드 캐러셀
```gherkin
Given 저장된 차량이 있는 상태
When 가상 차고 탭이 표시됨
Then 다크 배경(primary) 카드 캐러셀로 차량 이미지 + 이름 + 스펙이 표시된다
And 하단에 가격 정보 바 (차량 가격 / 월 납부금)가 표시된다
And 페이지 인디케이터 dots가 표시된다
And "에이카 상담 기록 >" 링크가 표시된다
```

## AC-3: 북마크 탭 — 2열 그리드
```gherkin
Given 저장된 차량이 있는 상태
When 북마크 탭을 선택
Then 필터 칩 (전체/일반/전기차)이 표시된다
And 저장된 차량이 2열 그리드 (VehicleCard.card + 북마크 아이콘)로 표시된다
```

## AC-4: 최근 본 탭 — 리스트
```gherkin
Given 저장된 차량이 있는 상태
When 최근 본 탭을 선택
Then 필터 칩 (전체/일반/전기차)이 표시된다
And 저장된 차량이 리스트 (VehicleCard.list)로 표시된다
```

## AC-5: 빈 상태
```gherkin
Given 저장된 카드가 없는 상태
When 차고 탭에 진입
Then "저장된 차량이 없습니다" 안내 + "AI에게 추천받기" 버튼이 표시된다
```

## AC-6: 마이페이지 프로필 + 로그아웃
```gherkin
Given 로그인된 상태에서 차고 헤더 톱니바퀴를 탭
When 마이페이지가 표시됨
Then 프로필 카드 (이름, 로그인 수단) + 설정 메뉴가 표시된다
And 로그아웃 탭 시 로그인 상태 초기화 + 홈으로 이동
```
