<objective>
## Goal
챗봇 탭에 AI 상담 UI를 구현하고, 키워드 매칭 MVP로 10개 시나리오의 자동 응답을 제공한다.

## Purpose
수입차 구매 과정의 정보 비대칭 해소 — AI 컨시어지의 첫 진입점. MVP에서는 키워드 매칭으로 즉각적인 상담 경험을 제공하고, 이후 Python RAG 전환 시 repository 교체만으로 대응한다.

- ChatMessage freezed 엔티티 + IChatRepository 인터페이스

- ChatBubble 신규 위젯 + 기존 위젯 재사용 조립
- AiChatPage 전체 조립 + ChatNotifier 상태 관리

## AC-1: 메시지 전송 및 키워드 매칭 응답
```gherkin
Given 챗봇 탭이 열려 있고 사용자가 메시지 입력란에 텍스트를 입력한 상태

Given 챗봇 탭 진입 시

```

    - Notifier 패턴 (AuthNotifier 스타일)
    - **ChatState**: immutable class with `messages` (List<ChatMessage>), `isStreaming` (bool), `streamingText` (String)
    - `build()`: 빈 상태 반환, `init()` 메서드로 비동기 Drift 로드
    - `sendMessage(String text)`:
      1. 사용자 메시지 생성 (UUID, ChatRole.user) → messages에 추가 → Drift 저장
      2. `isStreaming = true`
      3. repository.getResponse() → 응답 텍스트
      4. Timer.periodic (30ms) streamingText 한 글자씩 추가 → state 업데이트
      5. 완료: ChatMessage 추가, isStreaming = false, Drift 저장
    - `clearHistory()`: messages 초기화 + Drift clearHistory
    - **chatRepositoryProvider**: go_api/ChatRepositoryImpl 사용 (MVP)
    - **chatProvider**: `NotifierProvider<ChatNotifier, ChatState>(ChatNotifier.new)`

    **AiChatPage 연결** (Task 2 결과물에 provider wire):
    - `ref.watch(chatProvider)` → messages, isStreaming, streamingText
    - 전송 → chatNotifier.sendMessage()
    - 퀵 액션 칩 onTap → chatNotifier.sendMessage()
    - 초기화 → chatNotifier.clearHistory()
    - 스트리밍 중: 마지막 ChatBubble에 streamingText + isStreaming=true
