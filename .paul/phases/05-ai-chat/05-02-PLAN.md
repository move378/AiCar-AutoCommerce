<objective>
## Goal
챗봇 헤더 우측 히스토리 버튼에 상담 목록 화면을 연결하고, 대화를 세션 단위로 그룹핑하여 과거 상담을 탐색할 수 있게 한다.

## Purpose
사용자가 이전 AI 상담 기록을 쉽게 찾아보고 참고할 수 있도록 하여 반복 상담을 줄이고 UX를 개선한다.

- ChatHistoryTable에 session_id 컬럼 추가 (Drift migration v2)
- ChatNotifier에 세션 자동 생성 로직
- ChatHistoryPage (세션 목록 UI)
- GoRouter /chat/history 라우트 + 헤더 버튼 연결
</objective>

## AC-1: 세션 기반 대화 그룹핑
```gherkin
Given 사용자가 챗봇에서 새 대화를 시작할 때
When 첫 메시지를 전송하면
Then 새 sessionId가 자동 생성되고,
     해당 세션의 모든 메시지에 동일 sessionId가 부여되며,
     Drift DB에 session_id와 함께 저장된다
```

## AC-2: 히스토리 목록 화면
```gherkin
Given 챗봇 헤더의 히스토리 버튼(🕐)을 탭하면
When ChatHistoryPage가 표시되면
Then 과거 세션 목록이 최신순으로 표시되고,
     각 항목에 날짜 + 첫 메시지 미리보기가 표시되며,
     세션을 탭하면 해당 대화 내용이 표시된다
```
