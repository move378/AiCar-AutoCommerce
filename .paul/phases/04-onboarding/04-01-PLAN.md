<objective>
## Goal
Splash → SNS 로그인 → 동의 화면 플로우를 구현하고 GoRouter auth redirect를 연결한다.

## Purpose
사용자가 앱을 처음 실행했을 때의 진입 플로우. MVP에서는 실제 API 연동 없이 UI + mock auth state로 구현. 실제 카카오/구글 로그인은 Backend 연동 시 활성화.

## Output
- splash_page.dart — 로고 + 자동 전환
- login_page.dart — SNS 로그인 버튼 (카카오, 구글/애플)
- consent_page.dart — 서비스 이용약관 동의
- marketing_consent_page.dart — 마케팅 수신 동의
- auth_provider.dart — mock auth state (isLoggedIn, login/logout)
- app_router.dart — auth redirect + splash/login/consent routes 추가
</objective>

## Architecture
- Auth state: Riverpod StateNotifier (isLoggedIn, user mock)
- GoRouter redirect: !isLoggedIn → /login, isLoggedIn + !consented → /consent
- Splash: 2초 후 auth 상태 확인 → redirect
</context>
