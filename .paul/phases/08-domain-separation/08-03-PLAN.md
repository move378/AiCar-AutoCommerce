<objective>
## Goal
차고 탭을 3탭 UI(가상차고/북마크/최근본)로 풀 구현하여 ConsultationCard 캐러셀, 전시장 목업, 북마크 차량 그리드, 최근 본 차량 리스트를 표시한다.

## Purpose
08-01/02에서 도메인과 Provider를 분리했으나 차고 탭은 placeholder 상태. Figma 기반 3탭 UI를 구현하여 MVP 차고 기능을 완성한다.

## Output
- `garage_page.dart` — 3탭 TabBar 구조 (가상 차고 / 북마크 / 최근 본)
- `garageProvider` — ConsultationCard 목록 관리
- `recentlyViewedProvider` — 최근 본 차량 추적 (인메모리)
- 가상차고 탭: ConsultationCard 캐러셀 + 전시장 목업
- 북마크 탭: 카테고리 칩 + 차량 그리드 (2열)
- 최근 본 탭: 카테고리 칩 + 차량 리스트
- flutter analyze 에러 0
</objective>
