## Goal
VehicleCard 엔티티와 ICardRepository를 도메인 목적에 맞게 분리하여 Vehicle(차량 탐색), ConsultationCard(AI 상담 추천), Bookmark(북마크), Garage(가상차고) 4개 도메인 경계를 명확히 한다.

## Purpose
Phase 7까지 VehicleCard + ICardRepository가 홈 탐색, AI 추천, 북마크, 차고를 모두 혼합 처리하여 라우팅 혼선(홈에서 차량 탭 → AI카드 페이지로 잘못 이동)과 저장 혼선(북마크 → 가상차고로 잘못 저장)이 발생. Phase 9 Garage 구현 전에 도메인 경계를 확립해야 한다.

## Output
- `Vehicle` + `ConsultationCard` freezed 엔티티
- `IVehicleRepository` + `IBookmarkRepository` + `IGarageRepository` 인터페이스
- go_api + supabase 듀얼 구현체 (6개 파일)
- 기존 `VehicleCard` 엔티티 + `ICardRepository` + `CardRepositoryImpl` 삭제
- flutter analyze 에러 0
</objective>
