<objective>
## Goal
챗봇 AI 응답에서 트리거되는 카드형 차량 추천 UI를 구현한다. 스와이프 가능한 카드 리스트로 추천 차량을 표시하고, 견적확인/가상차고 저장 액션을 제공한다.

## Purpose
AI 상담 → 카드형 추천 → 견적/차고 플로우의 핵심 중간 단계. 사용자가 추천 차량을 시각적으로 비교하고 행동(견적/저장)으로 연결한다.

## Output
- VehicleCard freezed 엔티티 + ICardRepository 인터페이스
- go_api/ 구현체 (목업 차량 데이터) + supabase/ 스텁
- CardFrontWidget (차량 카드 앞면)
- CardListPage (스와이프 가능한 카드 리스트)
- 챗봇 → 카드 리스트 네비게이션
</objective>

## AC-1: 카드형 차량 추천 데이터
```gherkin
Given AI 상담에서 차량 추천 시나리오가 트리거되면
When 카드 리스트 페이지로 네비게이션하면
Then 추천 차량 목록이 카드 형태로 표시되고,
     각 카드에 차량명, 가격, 이미지 placeholder, 주요 스펙이 표시된다
```

## AC-2: 카드 스와이프 및 액션
```gherkin
Given 카드 리스트가 표시된 상태에서
When 좌우로 스와이프하면
Then 다음/이전 카드로 전환되고,
     카드 하단의 "견적확인"/"가상차고 저장" 버튼이 동작한다 (MVP: SnackBar)
```
