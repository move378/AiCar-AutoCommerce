## Goal
Create three navigation widgets — AiCarTabBar (GNB 5탭), AiCarTabs (콘텐츠 탭), AiCarHeader (페이지 헤더) — for app shell and page-level navigation.

## Purpose
These widgets form the navigation skeleton. AiCarTabBar is the GNB bottom nav used in MainShell (Phase 3). AiCarTabs are used inside pages for content switching. AiCarHeader provides consistent page headers.

- `presentation/widgets/tab_bar/aicar_tab_bar.dart` — GNB 5탭 bottom navigation
- `presentation/widgets/tab_bar/aicar_tabs.dart` — Horizontal content tab switcher

</objective>
