<objective>
## Goal
홈 탭에 차량 탐색 UI(추천 캐러셀 + 전체 목록 + 카테고리 필터)를 구현하고, 시승찾기 탭에 브랜드 전시장 링크 목록을 구현한다.

## Purpose
GNB 4탭 중 홈과 시승찾기가 placeholder 상태. MVP에서 사용자가 앱 진입 시 바로 차량을 탐색하고, 브랜드 전시장을 방문할 수 있어야 한다.

## Output
- `home_page.dart` — 추천 차량 캐러셀 + 전체 차량 리스트 + 카테고리 필터
- `home_provider.dart` — 차량 목록 상태 관리 (Riverpod Notifier)
- `test_drive_page.dart` — 브랜드 전시장 목록
- `test_drive_webview_page.dart` — WebView로 브랜드 전시장 앱 내 로드
</objective>
