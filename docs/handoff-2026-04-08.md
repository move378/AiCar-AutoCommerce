## 핵심 설계 결정 (CARL 기록됨)

### flutter-010: Vehicle 리네이밍 안 함
- CarDto/CarMapper로 백엔드 `/cars` API 매핑 흡수
- Vehicle 엔티티 이름 유지, 필드만 확장 (nullable)
- 이유: Drift BookmarkTable.vehicleId 스키마 호환, 20+ 파일 리네이밍 리스크 회피
- `/vehicles` API 활성화 시 `VehicleTrim` 별도 엔티티로 분리

### 도메인 분리 (기존 결정 유지)
- `Car` (백엔드 /cars) = 카탈로그 데이터 (public, no user_id)
- `Vehicle` (Flutter domain) = 앱 내 차량 정보 엔티티 (CarDto에서 매핑)
- `MyCar` (백엔드 /cars/register) = 사용자 등록 차량 (user_id)
- `ConsultationCard` = AI 상담 결과 (vehicleId 참조, Flutter 로컬)
- `Bookmark` = 찜 목록 (vehicleId 참조, Drift 로컬)
